# AbayaCloset

AbayaCloset is an e-commerce web application for selling abaya products online. The project appears to be a Visual Studio-based solution and is packaged as a ZIP archive in this repository.

## Overview

This project is intended to provide a storefront experience where customers can browse products, view details, and complete purchases in a simple online shopping flow.

## Project Structure

- `AbayaCloset/` - main application source files and project content
- `.vs/` - Visual Studio metadata and local editor settings
- solution/project files for the app

## Requirements

Before running the project, make sure you have:

- Visual Studio 2022 or later
- .NET SDK compatible with the project
- A local database or connection string configured for the app

## Getting Started

1. Download or clone this repository.
2. Extract the ZIP file if needed.
3. Open the solution file in Visual Studio.
4. Restore NuGet packages.
5. Build the solution.
6. Run the project in debug mode.

## Typical Run Flow

- Start the web application
- Open the app in the browser
- Browse products
- Add items to cart
- Proceed through checkout
- Complete the purchase flow

## Notes

This repository currently includes a packaged project archive (`AbayaCloset.zip`) rather than the extracted working directory. If needed, unzip the project and open the solution file from the extracted folder to work on it locally.
